## Sobre o projeto

O site foi criado para apresentar projetos reais de forma visual, responsiva e orientada à contratação. A experiência combina identidade editorial, movimentos suaves, profundidade 3D e estudos de caso com links para os produtos publicados.

### Principais destaques

- Interface autoral e totalmente responsiva
- Estudos de caso de sites e sistemas publicados
- Galeria de vídeos, reels e fotografia
- Animações e interações para mouse e toque
- Contato direto pelo WhatsApp
- Metadados sociais e imagem de compartilhamento
- Área de processo criativo e atuação profissional

## Tecnologias

- React 19
- Next.js 16
- TypeScript
- Vinext e Vite
- CSS responsivo com animações personalizadas
- Cloudflare Workers e D1
- Drizzle ORM

## Executar localmente

Requisitos: Node.js 22.13 ou superior.

```bash
npm install
npm run dev
```

Para validar a versão de produção:

```bash
npm run build
npm test
```

## Estrutura principal

```text
app/
  page.tsx           conteúdo e estrutura do portfólio
  globals.css        identidade visual e responsividade
  MotionEffects.tsx  movimentos e interações
public/
  cases/             imagens dos estudos de caso
  projects/          vídeos e trabalhos audiovisuais
```
